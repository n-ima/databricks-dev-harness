# ADR-0010: 品質契約の採用と人が読める日本語文書

日付: 2026-09-15。状態: accepted（利用者の採用指示。実装の検証状態は証拠記録を参照）。

## 決定

前回の読取専用品質診断とintake/build/reviewへの統合方針を採用する。文書の日本語化と、業務・データ・画面・外部境界をレビューできる構成を採用する。機械ID、API、コード、固有名詞、正確性が必要な引用は原語を維持し、日本語で意味を補う。過去の候補や承認済み文書のhashは書き換えない。

## 根拠と比較

現行intakeには英語本文の独立生成があり、日本語テンプレートだけの修正では再発する。テンプレートと生成を一本化する。用語とシステム境界は共通理解のため必要だが、全案件へ同じ巨大帳票を要求しない。これは[arc42の境界の整理](https://docs.arc42.org/section-3/)と[用語集の指針](https://docs.arc42.org/section-12/)を参考にした本ハーネスの判断である（2026-09-15確認）。

[GOV.UKのプロトタイプ指針](https://www.gov.uk/service-manual/design/making-prototypes)は検証する問いに応じた低・高忠実度の試作を扱う。これを参考に、画面の配置や導線が不確かな場合だけ軽量HTMLの紙芝居を先行させる。入力の検証が目的なら最初からfixtureモックでよい。二つの完成品を作る工程は採用しない。
