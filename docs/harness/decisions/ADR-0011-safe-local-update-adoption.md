# ADR-0011: 案件保護を既定とするローカル更新入口の正式採用

日付: 2026-09-15。状態: accepted。

## 採用の根拠と範囲

利用者は、前回の「正式採用し、次版として公開するところまで進めてよいですか」に対して「進めてください」と回答した。この指示に基づき、[安全更新設計](../design/SAFE_LOCAL_UPDATE.md)を0.6.0として採用し、既存private GitHubのmainへ公開する。

対象はローカル更新CLI、clone/ZIP展開先の固定snapshot、既定の案件保持と競合停止、適用後hash照合、両providerの更新workflow、日本語の初回/次回手順。新しい依存・実行権限・課金・本番配備を追加しない。ハーネス自体をDatabricksへ配備しない。個別案件への反映は別依頼であり、今回行わない。未採用HARD-03を含めない。

## 検証と配布

前回の設計・実装・forward独立レビューを基礎に、今回の公開用snapshotを再検証する。元の0.4.0/0.5.0配布物を上書きしない。安全更新の判断を毎回の「保持」指示に依存させず、失敗時は差分を保持して停止する。任意コマンドや同一権限の敵対的writerを封じるOS sandboxではない。

初回だけ旧版案件から信頼済み0.6.0実行器を外部起動し、以後は案件内へ導入された入口を使える。旧版CLIが将来の形式に未対応なら、信頼済み新版実行器へ切り替える。全更新を無承認で適用したり、個別案件を一括更新したりする採用ではない。成熟度L1を維持し、実provider/実Databricks/実案件での未確認範囲を公開時にも明示する。
