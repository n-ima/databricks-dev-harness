# 採用済み0.7.1の公開と0.7.2での記録書式訂正

## 目的と承認

利用者の「正式採用してよい」「すべて承認するので進めてください」に基づき、ADR-0013の改善を取り込み可能な新版としてprivate GitHub mainへ公開する。公開手順はdocs/harness/operations/HARNESS_DEVELOPMENT.md。既存の0.7.0、案件固有の変更、無関係な未追跡backupを保持する。案件適用・Databricks操作・課金provider試験は含まない。

0.7.1は公開済みだが、完了記録の発行で以下の旧IDの書式が拒否された。実質条件は変えず旧番号から数字の中間区切りを除き、既存parserが受理するPUB-01〜04へ訂正する。公開済み0.7.1の固定配布物・レビューは保持し、記録訂正を0.7.2として公開する。旧IDと新IDの対応は各項目の順番で1対1。0.7.2についても以下の配布・更新・公開条件を確認する。

## 受入条件

- PUB-01: 正式採用の記録と0.7.1の変更・互換性・移行案内があり、未検証を区別する。
- PUB-02: 版・stamp・管理ファイル・生成資産が一致し、回帰とGit改行往復が成功する。skipを成功に数えない。
- PUB-03: 0.7.0からcacheなし取得元/固定配布物の更新が成功し、案件固有ファイル保持・競合時の無変更・旧版不変を確認する。
- PUB-04: 独立レビュー済み対象だけを通常pushし、private remote mainのSHA一致とCIの実状態を確認する。CI未実行・失敗を成功にしない。
